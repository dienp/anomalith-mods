# Refine the Inventory storage icon

## Why

The Storage icon is small, tinted, and too close to the edge of the tooltip.

## What Changes

Give the icon room beside the quantity and use the Storage screen's `x 001` format.
Add an Inventory Storage Preview ON/OFF control in Other Settings.

## Capabilities

- Modified capability: `inventory-storage-preview`.

## Impact

Updates the Inventory tooltip's storage row.
