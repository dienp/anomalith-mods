# Verification

ScriptEngine loaded the Release DLL in a running game. Live Inventory
checks confirmed that the tooltip matched the repository count for
Thermal Ice Bar and other selections, including items with zero in storage.

The game displayed its Storage tab icon beside x 084 for Shotgun Shells.
The live probe also confirmed the icon appeared beside zero counts.

In Options → Other Settings, the Inventory Storage Preview row switched OFF
and back ON. Inventory tooltips omitted the count while OFF and showed
it again while ON. The mod logged both setting changes.

Highlight a carried item and compare the tooltip count with Base Storage.
Move between items to confirm the value follows the selection. Hover an
item near the edge of the Inventory to check that the tooltip fits.
