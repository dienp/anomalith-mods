# Install with BepInEx

## Why

Players need a normal startup install for Minimap.

## What changes

Ship Minimap as a standard BepInEx plugin and document the new install path. Keep ScriptEngine available for local development.

## Capabilities

### Modified Capabilities

- `live-minimap`: Support direct BepInEx startup.

## Impact

Updates installation and release packaging alongside the other ANOMALITH mod.
