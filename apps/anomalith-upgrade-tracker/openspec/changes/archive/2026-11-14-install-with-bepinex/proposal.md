# Install with BepInEx

## Why

Players need a normal startup install for Upgrade Tracker.

## What changes

Ship Upgrade Tracker as a standard BepInEx plugin and document the new install path. Keep ScriptEngine available for local development.

## Capabilities

### Modified Capabilities

- `upgrade-materials-tracking`: Support direct BepInEx startup.

## Impact

Updates installation and release packaging alongside the other ANOMALITH mod.
