# Add an Auto Reload setting

## Why

Players can already control Minimap and Pinned Item in Other Settings. Auto Reload needs the same in-game control.

## What Changes

- Add a native Auto Reload ON/OFF selector to Other Settings.
- Apply changes immediately and persist them in the existing mod configuration.
- Keep the regular weapon reload action available in both settings.

## Capabilities

### Modified Capabilities

- `auto-reload` gains an in-game control.

## Impact

Auto Reload owns the setting and works as a standalone BepInEx plugin.
